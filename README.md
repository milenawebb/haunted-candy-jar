# Haunted Candy Jar

A spooky Halloween to-do and focus timer app where your tasks live as glossy hard candies in a glass jar. Complete them before they decay!

## Local development

```bash
npm run dev
```

## Build

```bash
npm run build
```

The output in `dist/` is a static bundle ready to deploy to Cloudflare Pages.
